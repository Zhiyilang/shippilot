# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-15

### Added
- Nine lifecycle inspectors: plan, create, verify, package, secure, release,
  configure, monitor, govern.
- Twenty deterministic fixers with re-verification after every write.
- Autonomy dial: assisted, supervised, hands-off.
- MCP server over stdio (spec 2025-11-25) with seven tools.
- GitLab Duo Agent Platform integration: agent-config, MCP client, three flows.
- SCI carbon accounting with two priced optimisations.
- Self-contained HTML receipts, append-only JSON audit trail.
- CLI, Gradio console, 245-assertion offline test suite.
- Risk acceptance waivers for findings that must not be auto-rewritten.
